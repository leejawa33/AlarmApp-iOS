# 알라미 미션 및 기능 조사

조사 기준일: 2026-11-13 (한국 시간)

## 1. 문서 목적과 확인 범위

알람천국의 후속 기능을 검토하기 위한 경쟁 앱 기능 목록이다. 알라미 공식 사이트, 공식 iOS 도움말, 공식 Android 도움말, 개발자가 제공한 스토어 설명을 기준으로 정리했다. 알라미 앱을 직접 조작하거나 유료 구독하여 확인한 결과는 아니다.

- **iOS 안내 확인:** 공식 iOS 도움말에 해당 기능이 안내되어 있다. 최신 앱에서 직접 확인했다는 뜻은 아니다.
- **공통 소개 확인:** 공식 제품 소개에 있으나 플랫폼별 세부 제공 범위는 확인하지 않았다.
- **Android 안내 확인:** Android 공식 자료에 근거한다. iOS 지원으로 해석하면 안 된다.
- **확인 필요:** 자료 간 설명이 다르거나 최신 버전·요금제별 조건을 확정할 수 없다.

이 문서는 기능 조사 자료이며 알람천국의 구현 범위를 확정하는 기획서는 아니다. 무료·유료 구분은 공식 문서가 명시한 경우에만 적었으며, 가격·체험 조건·제공 범위는 국가와 버전에 따라 달라질 수 있다.

### 1.1 알람 스타일: 알람·퀵알람·습관 알람

추가 조사일: 2026-11-13. 사용자가 확인한 앱의 세 가지 분류를 공식 iOS 자료와 대조했다. 공식 iOS 이름·이모지 공지도 **기본 알람, 퀵 알람, 습관 알람**을 명시한다. 따라서 이 구분은 미션 종류와 별개의 **알람 사용 목적·설정 흐름에 따른 구분**으로 정리한다. 출처: [iOS 알람 이름·이모지 공지](https://alarmy-ios.zendesk.com/hc/en-us/articles/51193686070169--Your-alarms-can-have-names-now-finally).

#### 알람 / 기본 알람

- ‘+’에서 알람을 선택한 뒤 시각·반복 요일·미션 등을 설정하는 일반적인 상세 알람이다.
- 공식 요일 반복 도움말에는 주중·주말을 빠르게 선택하는 옵션도 안내된다.
- 이름과 이모지는 알람을 구분하기 위한 표시 정보다. 최신 이름 공지는 이름을 비워둘 수도 있다고 설명한다.
- **미확정:** 날짜 지정 단발 알람의 범위, 현재 무료·유료 상세 옵션과 최신 기본값은 이 자료만으로 확정하지 않는다.
- 출처: [iOS 요일 반복](https://alarmy-ios.zendesk.com/hc/ko/articles/360004422933), [iOS 이름·이모지](https://alarmy-ios.zendesk.com/hc/en-us/articles/51193686070169--Your-alarms-can-have-names-now-finally).

#### 퀵알람 / Quick Alarm / Power Nap

- 한국어 공식 도움말의 ‘퀵 알람’과 영문 도움말의 ‘Power Nap’은 **같은 문서 ID 360004393534**를 사용한다. 이 문서의 기존 ‘낮잠 알람 / Power Nap’은 퀵알람을 뜻하며 별도 네 번째 스타일로 세지 않는다.
- 설정 흐름: 알람 목록의 ‘+’ → 퀵 알람 → 몇 분 뒤 울릴지 선택 → 소리·진동 선택 → 저장.
- 도움말 예시는 1분·5분·10분·15분·30분·1시간이다. 최신 앱에서 다른 값이나 직접 입력을 지원하는지는 확인 필요다.
- 미션·벨소리·음량의 개별 상세 설정을 생략해 빠르게 등록하는 일회성 알람이다.
- 내장 스피커 재생·알람음 점점 크게 등 앱 전체 설정은 적용될 수 있다. 빠른 설정이라고 전체 음향 설정과 분리되는 것은 아니다.
- 퀵알람 위젯도 공식 iOS 도움말에 안내된다.
- 출처: [한국어 퀵알람 안내](https://alarmy-ios.zendesk.com/hc/ko/articles/360004393534), [영문 Power Nap 안내](https://alarmy-ios.zendesk.com/hc/en-us/articles/360004393534--Power-Nap-What-is-the-Power-Nap-for), [iOS 퀵알람 위젯](https://alarmy-ios.zendesk.com/hc/ko/articles/360004487734).

#### 습관 알람 / Habit Alarm

- 공식 iOS 공지는 **25.36.0에서 출시**했다고 안내한다.
- 설정 흐름: 알람 목록의 ‘+’ → 습관 알람 → 일반 알람 에디터에서 알람 설정과 실천할 습관 설정.
- **한국어 iOS 공지 기준 흐름:** 알람 해제 → 설정한 습관을 수행하는 화면 → 습관 실천 → 완료 버튼 → 해당 요일에 초록 체크 표시.
- 공식 예시는 물 한 잔 마시기, 침대 정리, 감사 일기 한 줄, 1분 스트레칭, 1분 명상이다. 예시 목록이 앱의 고정 프리셋 전체라는 뜻은 아니다.
- 완료 버튼과 체크 표시가 안내되므로, 이 자료만으로 실제 행동을 카메라·센서가 자동 검증한다고 해석할 수 없다.
- ‘알람을 끄기 위한 미션’과 ‘알람을 끈 뒤 이어지는 습관’을 구분해야 한다. 습관 자체를 마칠 때까지 알람 소리가 계속 난다고 단정하지 않는다.
- **미확정:** 무료·유료 조건, 사용자 지정 습관의 범위, 여러 습관 연결, 연속 달성일·통계, 누락일 보정, 미완료 시 재알림과 미션 조합 범위.
- 출처: [한국어 iOS 습관 알람 출시 안내](https://alarmy-ios.zendesk.com/hc/ko/articles/51194316790809), [영문 iOS 안내](https://alarmy-ios.zendesk.com/hc/en-us/articles/51194316790809--Introducing-Habit-alarm-Start-your-morning-routines-off-right).

#### 알람 스타일과 미션을 구분하는 기준

- 알람 스타일은 **어떤 목적으로 어떻게 예약하고, 해제 후 어디로 이어지는가**에 대한 구분이다.
- 미션 종류는 **울리는 알람을 해제하기 위해 무엇을 하는가**에 대한 구분이다.
- 따라서 습관 알람을 수학·흔들기와 같은 미션 목록의 한 종류로 추가하지 않는다.
- 알람천국에 도입한다면 예약 정보, 미션 설정, 습관 완료 기록을 각각 구분해 설계하는 방안을 검토할 수 있다. 이는 제품 설계 제안이며 알라미 내부 구조에 대한 설명은 아니다.

## 2. 미션 목록

공식 미션 비교 글은 9종을 소개한다. AI 미션과 집 안 물건 찾기는 같은 미션으로 설명하므로 별도로 중복 집계하지 않는다. 아래 기본 동작은 [공식 9종 비교 글](https://alar.my/en/blog/how-to-choose-alarmy-mission)을 요약했다.

| 번호 | 미션 | 기본 동작 | 분류 | 확인 범위 |
|---|---|---|---|---|
| 1 | 수학 문제 | 계산 문제의 답을 입력 | 인지 | 공통 소개 확인 |
| 2 | 기억력 | 표시된 타일 위치를 기억하고 선택 | 인지 | 공통 소개 확인 |
| 3 | 따라쓰기 | 제시된 단어나 문장을 입력 | 인지 | 공통 소개 확인 |
| 4 | 흔들기 | 휴대폰을 정해진 횟수만큼 흔들기 | 신체 활동 | 공통 소개 확인 |
| 5 | 스쿼트 | 정해진 횟수의 스쿼트 수행 | 신체 활동 | 공통 소개 확인 |
| 6 | 걷기 | 정해진 걸음 수 달성 | 신체 활동 | 공통 소개 확인 |
| 7 | 사진 | 미리 등록한 장소·대상의 사진을 다시 촬영 | 장소·카메라 | 공통 소개 확인 |
| 8 | QR/바코드 | 등록한 QR 또는 바코드 스캔 | 장소·카메라 | 공통 소개 확인 |
| 9 | 집 안 물건 찾기 / AI 미션 | 무작위로 제시된 물건을 찾아 카메라에 보여주기 | 사물·카메라 | iOS 안내 확인 |

### 2.1 수학 문제

- 난이도를 선택해 계산 문제를 푸는 방식이다.
- 정확한 연산 종류, 난이도별 숫자 범위, 문제 수 선택 범위는 앱에서 확인해야 한다.
- 출처: [공식 미션 소개](https://alar.my/en/blog/alarmy-wake-up-mission).

### 2.2 기억력

- 최신 공식 비교 글은 타일 위치를 기억하는 방식으로 소개한다.
- 이전 공식 소개에는 숫자 순서를 기억하는 설명도 있어, 세부 유형은 버전·플랫폼별 확인이 필요하다.
- 출처: [공식 9종 비교](https://alar.my/en/blog/how-to-choose-alarmy-mission), [이전 미션 소개](https://alar.my/en/blog/alarmy-wake-up-mission).

### 2.3 따라쓰기

- 단어나 문장을 입력하는 방식이며 공식 비교 글에는 사용자 지정 문장도 언급된다.
- 대소문자·공백·문장부호 처리, 사용자 지정 문장 제공 요금제는 확인 필요다.
- 출처: [공식 9종 비교](https://alar.my/en/blog/how-to-choose-alarmy-mission).

### 2.4 흔들기·스쿼트·걷기

- 각각 흔든 횟수, 스쿼트 횟수, 걸음 수를 완료 조건으로 사용한다.
- 흔들기 횟수 조절이 공식 소개에 안내된다.
- 센서 종류, 자세 판정 방식, 최소·최대 횟수는 제품 구현을 추정하지 않고 별도 확인한다.
- Android 프리미엄 안내에는 걷기·스쿼트가 유료 미션으로 기재되어 있다. 이를 iOS 요금제에 그대로 적용하지 않는다.
- 출처: [공식 미션 소개](https://alar.my/en/blog/alarmy-wake-up-mission), [Android 프리미엄 안내](https://alarmy-android.zendesk.com/hc/en-us/articles/900001614846-Let-me-introduce-to-you-Alarmy-Premium-features).

### 2.5 사진·QR/바코드

- 사진은 사전 등록한 장소나 대상을 다시 촬영하는 방식이다.
- QR/바코드는 사전 등록한 코드를 다시 스캔하는 방식이다. 공식 안내는 치약 같은 생활용품이나 침대에서 떨어진 장소의 QR을 예시로 든다.
- 사진과 QR은 서로 다른 미션이다. 장소 사진의 유사성 판단과 코드 값 일치를 혼동하지 않는다.
- 출처: [공식 미션 소개](https://alar.my/en/blog/alarmy-wake-up-mission), [Android QR/바코드 안내](https://alarmy-android.zendesk.com/hc/en-us/articles/360004242494--Mission-How-do-I-use-the-QR-Barcode-mission).

### 2.6 집 안 물건 찾기 / AI 미션

- 컵·의자·세면대·커튼 등 제시된 대상을 제한 시간 안에 카메라에 보여준다.
- 다른 대상으로 다시 뽑기가 가능하다.
- 시간을 10초씩 최대 5회 추가할 수 있다고 iOS 도움말에 안내되어 있다.
- 출제할 물건의 카테고리를 선택할 수 있다.
- iOS 도움말은 25.42.0 이상에서 제공한다고 안내한다. 무료·유료 조건과 실제 인식 방식은 확인 필요다.
- 출처: [iOS 집 안 물건 찾기 안내](https://alarmy-ios.zendesk.com/hc/en-us/articles/52947520209945--New-Morning-Mission-Find-an-Item-at-Home).

기상 재확인은 일반 스누즈와 다르다. 스누즈는 해제를 미루는 기능이고, 기상 재확인은 해제 이후 다시 잠들었는지를 응답으로 확인하는 기능이다. iOS 도움말은 조용한 확인 알림과 제한 시간 내 응답 과정을 설명한다. 세부 대기·응답 시간은 현재 앱에서 확인해야 한다.

## 7. 무료·유료 및 운영 기능

- 메모 읽어주기는 사용자가 알라미 앱에서 유료 서비스로 확인했다(2026-11-13 대화). 공식 iOS 공지로 기능과 메모 필드의 존재를 교차 확인했으며, 현재 상품별 제공 조건·읽기 간격은 추가 확인이 필요하다. 알람 이름만 읽는 기능으로 좁혀 설명하지 않는다.
- 무료 사용과 앱 내 구독을 함께 제공한다. 무료 다운로드와 모든 기능 무료 제공은 구분한다.
- 공식 iOS 도움말은 기상 재확인과 소리 강화 팩을 유료 기능으로 설명한다.
- iOS 코골이 하이라이트는 무료·구독 사용자의 접근 범위를 구분한다.
- 공식 iOS 도움말에는 구독 관리, 구매 복원, 환불, 무료 체험 관련 안내가 있다. 현재 가격과 체험 자격은 스토어에서 확인해야 한다.
- Android 프리미엄 안내에는 광고 제거가 명시되어 있다. iOS 최신 상품별 광고 제거 범위는 별도 확인한다.
- 앱 내 피드백·도움말 경로가 안내되어 있다.
- 출처: [공식 사이트](https://alar.my/en), [iOS 구독 도움말](https://alarmy-ios.zendesk.com/hc/en-us/sections/360000933694-Premium-Subscription), [iOS 구독 만료 안내](https://alarmy-ios.zendesk.com/hc/en-us/articles/360038726793--Guide-My-premium-access-has-been-expired-What-happens-to-my-alarms-I-used), [Android 유료 안내](https://alarmy-android.zendesk.com/hc/en-us/articles/900001614846-Let-me-introduce-to-you-Alarmy-Premium-features).

## 9. 알람천국 후속 검토에 활용하는 방법

아래는 조사 결과를 활용하기 위한 제안이며, 알라미의 기능 사실이나 확정된 구현 계획은 아니다.

1. **추가 미션 후보:** 수학 → QR/바코드 → 기억력 순으로 상세 요구사항 검토.
2. **기상 유지 후보:** 기상 재확인, 미션 연속 수행, 기상 소요 시간 기록.
3. **일상 편의 후보:** 다음 회차 건너뛰기, 알람 복제, 낮잠 알람, 미션 난이도 선택.
4. **별도 확장 후보:** 수면 분석·코골이·AI 사물 인식은 권한과 판정 품질 검토가 필요한 별도 범위로 다룸.

알람천국의 확정 요구사항은 `docs/iOS_알람앱_기획서.md`, 진행 상태는 `CLAUDE.md`에서 관리한다. 이 조사 문서에는 프로젝트 구현 완료 여부나 작업 진행 상태를 기록하지 않는다.
