# 알람천국 iOS 기획서 — 기본 기능 및 날짜 예외·메모·퀵알람·미루기 확장

최종 수정: 2026-11-15 (최초 2026-11-09)<br>
표시명: 알람천국 / iOS: AlarmApp-iOS / Android: AlarmApp-Android

## 검토 요약

- Phase 1: iPhone / Swift+SwiftUI **네이티브만**
- 크로스플랫폼(Flutter, RN, KMP 등) **제외**
- Android는 별도 저장소의 네이티브 앱으로 관리한다. 날짜 예외·메모·퀵알람·미루기의 제품 규칙은 양 플랫폼에 동일하게 적용하고, OS 알람 예약은 플랫폼별로 구현한다(코드 공유 목표 아님).
- 0~10절은 기본 기능 범위이며, 날짜 예외·메모·퀵알람·미루기 확장에는 **11절의 규칙을 우선 적용**한다. 확장 구현 시 기존 데이터와 알람 동작을 보존한다.

## 1. 제품 정의

강제 기상 유틸리티. 미션 완료 전까지 앱 안에서 알람을 끌 수 없다. 예외는 미션 없는 **퀵알람**(11.7)뿐이며, **미루기**(11.6)는 끄는 것이 아니라 N분 뒤 다시 울리게 하는 기능이다.  
참고: 알라미. 개인용 MVP (1:1 복제 아님).

## 3. 핵심 흐름

1. 알람 on → 시각에 AlarmKit 시스템 울림  
2. 시스템 주 액션으로 앱 열기  
3. 앱 알람 실행 화면 → 미션 시작 → 미션 완료 → 알람 정지  

규칙:
- 시스템 주 버튼 = 앱으로 보내기 (미션 없는 즉시 종료를 기본으로 두지 않음). 시스템 알림의 보조 버튼 문구: "미션하러 가기"
- OS가 Stop을 강제 노출하면 한계는 리스크로 수용
- 실행 화면은 **미션 완료로만** 닫힌다 (뒤로가기·스와이프 불가). 알람별 미루기를 켠 경우 `미루기` 버튼을 누르면 소리가 멈추고 정해진 시간 뒤 다시 울리며, 이때도 끄는 경로는 미션 완료뿐이다(11.6)
- 퀵알람은 미션이 없어 시스템 알림에서 바로 끌 수 있다(11.7)
- 미션 완료 시 지금 울리는 알람만 정지하고, 반복 예약은 유지한다
- 앱을 열었을 때 시스템 알람 소리가 멈춰 있으면, 미션이 끝날 때까지 앱이 알람 소리를 직접 반복 재생한다(무음 모드에서도)
- 알람을 찾을 수 없거나 문구 파일이 없어도 **미션 없이 꺼지지 않는다** (기본 미디어·소리 + 흔들기로 대체)
- 미리보기는 **편집 화면에서만**, `미리보기 종료` 표시. 미리보기에서도 미션을 해 볼 수 있지만 알람을 정지하지 않는다

## 4. 기능 (MVP)

### 설정
- 메인 우측 상단 톱니바퀴 → 설정 화면
- 언어: 설정 화면의 "언어 ›" 한 줄 → 언어 선택 화면(시스템 설정 / 한국어 / English). 고르면 즉시 적용. 시스템 언어가 한·영이 아니면 한국어
- 권한 안내: 알람 권한이 **꺼져 있거나 아직 묻지 않았을 때만** 표시. `설정 열기`는 미결정이면 앱 안 권한 창, 허용·거부 상태면 iPhone 설정의 알람천국 항목으로 이동
- 테마: Phase 1에서는 없음(라이트 고정). 2차에서 라이트/다크/시스템 추가

### 알람
- 최대 10개 (초과 시 추가 차단)
- 요일 1개 이상 필수 + 오전/오후 시간
- 타이틀 필수
- on/off, 삭제(로컬+AlarmKit). 삭제는 리스트에서 왼쪽으로 밀기 · 카드 길게 누르기 · 편집 화면 휴지통(확인창)
- 알람 권한이 꺼져 있으면 메인 상단에 경고 배너(설정 경로 안내 + `설정 열기`)
- 리스트: 시간·요일·타이틀·on/off·다음 울림까지 N시간 M분 (해당 없으면 숨김)
- 생성 기본값: 미션=흔들기, 미디어=`와장창 댕댕이` 영상, 소리=`아침이 왔다잖아` (카탈로그 `default: true`), 시각 07:00, 요일 월~금, 타이틀 빈칸(입력 필수), 따라쓰기 문장 = 전체
- 남은 시간은 분 단위 올림(1분 30초 → 2분)
- 빈 목록: 빈 상태 + 추가 CTA

### 미션 (알람당 1개 필수)
1. **흔들기 10회** — 가속도 기준(4.0g, 실기기에서 조정 예정). 진행 링과 n/10 표시, 7회부터 "거의 다 왔어요!"
2. **따라쓰기** — 앞뒤 공백만 무시하고 **완전 일치**(대소문자 구분). 입력이 일치하는 순간 완료
   - 문장은 카테고리 4개(자기 확언 / 사랑 / 학업 / 동기부여) × 3문장 = 12문장, 각 문장에 한국어·영어가 있다
   - **알람마다 출제할 문장을 고른다**: 편집 화면에서 따라쓰기를 고르면 "미션 문장 ›" → 미션 문장 고르기 화면(카테고리 탭 · 탭별 전체 선택 · 문장별 체크, 0개면 확인 불가). 알람이 울리면 고른 문장 중 무작위 하나
   - 앱 언어의 문장으로 출제·판정한다. 문장 선택은 언어를 바꿔도 유지된다
   - 문장 작성 기준: 짧게, 띄어쓰기가 헷갈리지 않게, 문장부호·숫자·이모지 없이. 영어는 첫 글자만 대문자, 중간 대문자와 아포스트로피 금지

### 실행 화면
- **전체 화면 배경 동영상**(음소거·반복 재생) 위에 날짜·큰 시각(24시간제 `HH:mm`)·타이틀·미션 시작
- 날짜·시각은 상단 1/3, 미션 시작은 하단. 영상은 이 영역을 비워 두고 만든다
- 실행 → 미션 → 완료("미션 완료! 좋은 아침이에요", 진동) → 닫힘. 울리는 동안 화면이 꺼지지 않는다

### 미디어·소리
- 미디어: 동영상 3개 번들 (모두 1080×1920 · 7초 루프 · 무음, 기본값은 강아지)
  - `media_puppy_crack.mp4` `와장창 댕댕이` — 강아지가 폰 화면을 마구 두드려 깨뜨리는 2D 일러스트
  - `media_cat_push.mp4` `책상 위 냥이` — 고양이가 앞발로 폰을 책상 끝까지 밀어내 아슬아슬하게 만드는 2D 일러스트
  - `media_shaking_clock.mp4` `들썩들썩 알람` — 알람 시계가 종을 울리며 좌우로 크게 흔들리는 2D 일러스트(민트 배경)
- 소리: 2개 번들 (mp3). 소리·미디어 표시명은 앱 언어를 따른다(한/영). AlarmKit 알람 소리는 같은 소리의 `.caf` 변환본, 앱 안 재생은 mp3
- 알람별 선택. 영상 소리는 쓰지 않고 알람 소리는 카탈로그 소리로 재생

## 6. 데이터

- Alarm, MissionType(shake|transcription), MediaAsset, SoundAsset, AppSettings, TranscriptionPrompt  
- Alarm: 시각·요일·타이틀·켜짐·미션·미디어·소리·**따라쓰기 문장 선택**(빈 값 = 전체)
- 확장(11절): 알람별 메모·읽기 설정, 알람별 미루기 설정(간격·횟수), 날짜 예외, 퀵알람, 회차·예약 정보
- SwiftData가 원본, AlarmKit은 파생. 저장 후 예약하고, 예약이 실패해도 데이터는 남기고 앱 시작·활성화 때 다시 맞춘다
- 미디어·소리·문장은 번들 파일(카탈로그·문구 JSON)이 원본이고 SwiftData에 저장하지 않는다

## 7. 권한

- **알람(AlarmKit)만 필수.** 설명문: "설정한 시각에 미션 알람을 울리기 위해 사용합니다."
- 권한 요청은 사용자 동작(알람 저장·켜기·`설정 열기`)에서만 한다. 앱이 활성화되기 전에 요청하면 시스템이 창 없이 거부하기 때문
- Core Motion(흔들기)은 가속도만 읽어 권한이 필요 없다. 알림·마이크·카메라·위치 권한 없음
- Widget Extension은 지금 없음(카운트다운 표시가 필요해지면 검토)
- 알람 권한 스위치로 바로 가는 공개 링크는 없다. 앱 설정 항목까지만 보낼 수 있다

## 8. 비범위

Phase 1: Android, iPad, iOS 25↓, 크로스플랫폼, 클라우드, 통계/유료, 잠금화면 장악, **다크 테마**. 단발 알람은 퀵알람(11.7)과 날짜 예외 회차(11.3)로, 스누즈는 미루기(11.6)로 한정해 확장에서 허용한다.  
별도 확장: 톤다운 다크 + 테마 설정(라이트/다크/시스템). Android는 별도 저장소에서 관리한다.

이번 확장(날짜 예외·메모·퀵알람·미루기)의 제외 범위: 요일별 다른 시각(시각이 다르면 알람을 따로 만든다), 순환(교대) 일정, 달력 직접 지정, 월 달력 전체 화면, 조용한 기상 모드, 음량 단계 전환, Watch·이어폰 우선 기상, 계정·로그인, 서버 백업·복원, 클라우드 동기화, 결제. 신규 미션·습관 알람도 포함하지 않는다.

## 9. 리스크

- 시스템 UI ≠ 앱 실행 UI  
- 시스템 Stop 100% 차단 불가 가능  
- 앱 kill 후 미션 강제 약함  
- 실기기·Mac 필수  
- 실행 화면 영상 재생이 알람 소리(오디오 세션)를 끊지 않아야 함  
- `아침이 왔다잖아`는 33.7초 — 알림 소리 30초 제한에 걸려 기본음이 될 수 있음(실기기 확인)  
- 흔들기 기준값·영어 키보드 자동 대문자·한글 조합 중 판정은 실기기 확인 필요  
- 따라쓰기 완전 일치 규칙상 띄어쓰기 실수로 실패할 수 있음 → 실기기에서 실패가 잦으면 규칙 재검토  

## 10. 디자인 톤 · 화면 와이어

### 브랜드
아침 햇살처럼 밝고, 미션 버튼은 힘차게.

| 토큰 | 안 | 역할 |
|------|-----|------|
| bg | `#FFF8F0` | 기본 배경 |
| brand-sun | `#FFC107` | 햇살 포인트, 토글 on |
| cta | `#FF3B30`~`#FF5A5F` | 미션 시작 등 |
| text | `#1A1A1A` / 실행화면 시각은 화이트+섀도 | |

피함: 다크 기본, 퍼플 네온, 무거운 세리프 신문 톤.

- UI 타이포: 둥근 산세리프 볼드 (SF Rounded 계열)
- 실행 화면 미디어는 전체 화면 배경 동영상(브랜드 타이포와 분리). 시각은 화이트+섀도로 영상 위 가독성 확보
- 미디어 연출: 깜빡임(화면 전체 번쩍임) 금지, 흔들림·금 효과로 표현
- 모션: CTA 스프링, 토글 점등, 미션 완료 짧은 피드백

### 화면 구조
- **메인:** 알람천국 워드마크 · 설정(톱니바퀴) · 권한 경고 배너(꺼져 있을 때) · 리스트(시간/요일/타이틀/남은 시간/on·off, 밀어서·길게 눌러 삭제) · 추가(10개면 비활성 + 안내) · 빈 상태
- **편집:** 시간·요일·타이틀·미션(+따라쓰기면 미션 문장)·미디어·소리 · 메모·읽기(11.5) · 미루기(간격·횟수, 11.6) · 다가오는 울림(11.2) · 미리보기 · 저장 · 삭제(휴지통)
- **미션 문장 고르기:** 취소 / 확인 · 카테고리 탭(고른 개수 배지) · 전체 선택 · 문장 체크
- **설정:** 일반(언어 ›) · 권한 안내(필요할 때만)
- **실행:** 전체 화면 배경 영상 + 레퍼런스 레이아웃(날짜·시각·뱃지·미션 시작). 미루기를 켠 알람은 미션 시작 아래에 `미루기 N분`(11.6). 뒤로가기로 끄기 없음
- **미리보기:** 실행 + 미리보기 종료
- **미션:** 흔들기 n/10 또는 따라쓰기 입력 → 완료 피드백 → 정지

카피 톤: 밝고 짧게. 레퍼런스 중앙 장문은 미디어 예시일 뿐 앱 기본 톤 아님.

## 11. 날짜 예외 · 메모 읽어주기 · 알람 미루기 · 퀵알람

### 11.1 목적과 범위

기존 알람을 유지한 채 다음 네 가지를 더한다.

1. **날짜 예외:** 특정 날짜만 시각을 바꾸거나 건너뛴다.
2. **메모 읽어주기:** 오늘 일어나야 하는 이유를 실행 화면에서 읽어 준다.
3. **알람 미루기:** 실행 화면에서 정해진 시간 뒤 다시 울리게 한다.
4. **퀵알람:** 몇 분 뒤에 한 번 울리는 미션 없는 알람.

- 기존 흔들기·따라쓰기, 영상·소리, 미션 완료 후 알람 정지 규칙은 유지한다.
- 알람은 지금처럼 **하나의 시각과 요일 집합**을 가진다. 요일마다 다른 시각이 필요하면 알람을 따로 만든다.
- 순환(교대) 일정, 달력 직접 지정, 월 달력 전체 화면은 이번 범위에 넣지 않는다.
- 저장은 기기 로컬을 기준으로 하며 계정·백엔드는 넣지 않는다.
- 사용자에게 보이는 모든 화면·안내·접근성 문구는 한국어·영어를 함께 제공한다.
- 자동 공휴일 조회·외부 캘린더 연동은 포함하지 않는다. 휴일은 사용자가 날짜 예외(건너뛰기)로 지정한다.

### 11.2 화면 구성과 사용자 흐름

- **메인:** 가장 가까운 실제 기상 예정 시각을 상단에 표시한다(날짜·시각·알람 이름·적용 이유·미션 요약·메모 요약). 적용 이유는 `기본 일정` / `이 날짜만 변경`을 구분한다. 그 아래에 기존 알람 목록과 퀵알람 진입을 둔다. 권한 경고와 설정 진입은 유지한다.
- **다가오는 울림:** 알람 편집 화면(또는 알람 상세)에서 앞으로의 울림을 날짜순 목록으로 보여 준다. 날짜를 고르면 날짜 예외 편집으로 간다. 변경되거나 건너뛴 날짜는 구분해 표시한다.
- **날짜 예외 편집:** 시각 변경 / 건너뛰기 / 메모 변경 / 변경 취소.
- **퀵알람 만들기:** 분 단위를 고르면 바로 예약한다(11.7).
- 목록과 날짜별 표시는 같은 계산 결과를 사용한다. 표시된 예정 시각과 OS 예약 결과를 별도 로직으로 계산하지 않는다.

표시 예:

> 다음 기상: 월요일 오전 5:30 · 이번 날짜만 변경
>
> 화요일 오전 7:00 · 기본 일정

### 11.3 날짜 예외

날짜를 선택하면 ‘이 날짜만 변경’을 기본 동작으로 제공한다.

| 동작 | 결과 |
|---|---|
| 시각 변경 | 해당 알람의 그날 시각을 교체. 원래 시각에 중복으로 울리지 않음 |
| 건너뛰기 | 해당 알람의 그날 회차만 제외 |
| 메모 변경 | 그날 읽을 메모만 변경(11.5) |
| 변경 취소 | 해당 날짜의 예외를 제거하고 기본 규칙으로 복귀 |

- 예외는 ‘대상 알람 + 알람 날짜’로 식별한다. 한 날짜의 수정으로 다른 알람이나 다른 날짜가 변경되지 않는다.
- 기본 일정 계산 → 날짜 예외 적용 → 최종 울림 시각·설정 결정 → OS 예약 순서로 처리한다.
- 시각 변경은 추가 알람 생성이 아니다. 같은 회차는 한 번만 울린다.
- 예외가 끝나면 다음 날짜부터 기본 규칙을 적용한다. 예외가 기본 시각을 바꾸지 않는다. **다음 주 같은 요일은 기본 시각으로 울린다.**
- 건너뛰기는 해당 날짜의 소리와 메모 읽기 모두 실행하지 않는다.
- 앞으로 계속 적용할 변경은 알람 편집에서 시각을 바꾸는 것으로 처리한다. 이미 걸린 날짜 예외는 유지한다.
- 이미 울리는 알람은 재계산 때문에 취소하지 않는다. 울리는 회차는 기존 미션 완료 흐름으로 처리한다.
- 지나간 날짜의 예외는 더 이상 쓰이지 않으므로 정리할 수 있다.

예: 월~금 07:00 알람에서 월요일만 05:30으로 변경하면 그 월요일 05:30에만 울리고, 화요일과 다음 주 월요일은 07:00으로 울린다.

### 11.4 미션·영상·소리 설정

- 날짜 예외는 시각·건너뛰기·메모만 바꾼다. 미션·영상·소리·문장 선택은 알람의 설정을 그대로 쓴다. 미션은 기존과 같이 한 회차당 정확히 하나다.
- 기존 알람은 동일한 요일·시각·켜짐 상태·미션·미디어·소리·문장 선택을 유지한다. 확장 때문에 예약을 중복 생성하지 않는다.

### 11.5 메모 읽어주기

알람 표시 이름과 읽을 메모는 별도 필드다. 메모는 미션 따라쓰기 문장과도 별개다.

- 알람별 메모, 읽기 켜기·끄기, 저장 전 ‘들어보기’를 제공한다.
- 특정 날짜의 메모는 ‘기본 메모 사용 / 이날만 다른 메모 / 이날은 읽지 않기’를 구분한다. 빈 문자열만으로 상속과 읽기 해제를 동시에 표현하지 않는다.
- 사용자가 작성한 한국어·영어 메모의 음성 언어를 지원하며, 앱 UI 언어와 사용자 메모 언어는 분리한다. 자동 언어 판별이 불명확한 경우 선택할 수 있게 한다. 사용자 메모를 임의 번역하지 않는다.
- 첫 제공 범위는 **실제 알람 실행 화면 진입 후 회차당 한 번 읽기**다. 화면 재렌더링·앱 복귀만으로 반복 재생하지 않는다.
- 메모 재생 중에도 미션을 바로 시작할 수 있다. 미션 시작·알람 완료·실행 화면 종료 시 음성 재생을 중단한다.
- 음성 재생 실패가 미션 수행이나 알람 정지를 막으면 안 된다. 메모 텍스트는 화면에서 확인할 수 있게 한다.
- 음성 때문에 알람 재생 세션을 종료하거나 미션 없이 알람을 끄지 않는다. 말소리를 알아들을 수 있는 믹싱·음성 재생 정책은 실기기 기준으로 정한다.
- ‘들어보기’는 시스템 예약과 알람 상태를 바꾸지 않으며 사용자가 중단할 수 있다.
- 미루기로 다시 울린 회차에서는 메모를 다시 읽지 않는다. 같은 회차로 본다.
- 잠금화면·앱 종료 상태에서 최초 울림과 동시에 메모를 읽는 기능은 이번 범위에 넣지 않는다.

예: 이름 ‘이른 출근’, 메모 ‘오늘은 여섯 시 반에 출발해야 해요. 출입증 챙기세요’.

### 11.6 알람 미루기

알람이 울린 뒤 미션을 하지 않고 정해진 시간 뒤에 다시 울리게 하는 기능이다. 알람 끄기가 아니다.

**알람별 설정**

| 항목 | 선택지 | 기본값 |
|---|---|---|
| 미루기 | 켜기 / 끄기 | 끄기 |
| 간격 | 1분, 3분, 5분, 10분, 15분, 20분, 25분, 30분, 45분, 60분 | 5분 |
| 횟수 제한 | 무제한, 1회, 2회, 3회, 5회, 10회 | 3회 |

**동작**

- 미루기를 켠 알람의 **실행 화면**에 `미루기 N분` 버튼을 둔다. 시스템 알림의 보조 버튼은 “미션하러 가기”로 유지한다.
- 누르면 지금 울리는 소리를 멈추고 실행 화면을 닫은 뒤, 설정한 간격 뒤에 같은 알람이 다시 울리도록 OS에 일회성으로 예약한다.
- 같은 회차에서 미룬 횟수를 센다. 횟수 제한에 도달하면 버튼을 숨기고, 이후에는 미션 완료로만 끌 수 있다. 무제한이면 숨기지 않는다.
- 다시 울린 알람도 같은 실행 화면·미션 규칙을 따른다. 알람을 끄는 경로는 **미션 완료뿐**이다.
- 미룬 뒤 앱을 종료해도 OS 예약으로 다시 울려야 한다.
- 미루기로 생긴 일회성 예약은 사용자가 만든 알람 수(최대 10개)에 포함하지 않는다.
- 미리보기에서는 미루기 버튼을 보여 주되 실제 예약은 만들지 않는다.
- 사용자가 알람을 끄거나 삭제하거나 날짜 예외로 건너뛰면 대기 중인 미루기 예약도 함께 취소한다.
- 버튼·알림 문구는 한국어·영어를 함께 제공한다.

### 11.7 퀵알람

몇 분 뒤에 한 번 울리는 가벼운 알람이다. 낮잠·타이머 용도로 쓴다.

- 분 프리셋: 1분, 5분, 10분, 15분, 30분, 60분. 고르면 바로 예약한다.
- **미션이 없다.** 시스템 알림에서 바로 끌 수 있다. 이는 ‘미션 완료 전까지 끌 수 없다’ 규칙의 명시적 예외다.
- 미디어·영상은 없고 소리는 카탈로그 기본 소리를 쓴다. 이름은 퀵알람임을 알 수 있게 자동으로 붙인다(한국어·영어).
- 한 번 울리거나 사용자가 취소하면 삭제된다. 반복하지 않는다.
- 퀵알람은 일반 알람 최대 10개 한도에 포함하지 않는다. 동시에 둘 수 있는 퀵알람 수는 상세 설계에서 정한다.
- 목록에서 남은 시간을 보여 주고 취소할 수 있다.

### 11.8 데이터와 예약 경계

아래는 논리적 구성이다. 실제 모델 이름과 테이블 분할은 구현 설계에서 정한다.

| 구성 | 역할 |
|---|---|
| 알람 | 기존 값(이름·시각·요일·켜짐·미션·미디어·소리·문장 선택) + 메모·읽기 여부·음성 언어 + 미루기 설정 |
| 날짜 예외 | 대상 알람·날짜, 시각 교체, 건너뛰기, 메모 정책 |
| 퀵알람 | 울릴 시각, 소리, 시스템 알람 ID |
| 회차·예약 정보 | 알람·날짜, 최종 울림 시각, 종류(정규·미루기·퀵), 시스템 알람 ID, 예약 결과, 미룬 횟수, 회차별 메모 재생 식별 |

- 알람과 설정이 원본이며 OS 예약은 파생 데이터다. 모든 변경은 서비스 계층을 통해 저장·예약 반영한다.
- 기존 ‘알람 하나 = 시스템 알람 ID 하나’를 전제하지 않는다. 날짜 예외·미루기·퀵알람은 한 번만 울리는 일회성 예약이 필요하다. 알람·회차·플랫폼 예약을 안정적인 식별자로 연결해 재계산 시 중복을 방지한다.
- 날짜 예외가 없는 알람은 지금처럼 요일 반복 예약을 유지한다. 예외가 걸린 기간의 처리 방식은 예약 한도와 앱 미실행 지속성 검증 결과로 정한다.
- ‘알람 없음’과 건너뛰기는 빈 요일이나 임의 시각이 아니라 명시적인 상태로 저장한다.
- OS 예약 실패 시 사용자 설정을 보존하고, 실제 예약되지 않은 회차를 예약 성공으로 표시하지 않는다. 재조정은 울리는 회차를 방해하지 않는다.
- 앱 재실행뿐 아니라 장기간 앱 미실행, 기기 재부팅, 시간대·날짜 변경을 고려한다. 매일 앱을 열어야만 예약이 이어지는 설계는 허용하지 않는다.
- 미래 일부 회차를 미리 예약하는 방식은 예약 한도·보충 동작·미실행 지속성을 검증한 범위 안에서만 제공한다. 보장할 수 없는 날짜까지 예약된 것처럼 표시하지 않는다.
- iOS·Android는 같은 입력에 같은 날짜별 결과를 산출하되 OS 권한·예약·재부팅 처리 방식은 플랫폼별로 구현한다.

### 11.9 수용 기준

1. 날짜 예외로 시각을 교체하면 원래 시각은 울리지 않고 다음 날짜(다음 주 같은 요일 포함)는 기본 규칙으로 울린다.
2. 건너뛰기와 변경 취소가 해당 알람의 해당 회차에만 적용된다.
3. 메모 기본값·날짜별 변경·이날 읽지 않기가 구분되며, 회차당 재생 중복과 음성 실패로 인한 알람 해제가 없다.
4. 미루기를 켠 알람에서 설정한 간격 뒤에 다시 울리고, 횟수 제한에 도달하면 버튼이 사라지며, 미션 완료 전에는 알람이 꺼지지 않는다. 앱을 종료해도 다시 울린다.
5. 알람을 끄거나 삭제하거나 건너뛰면 대기 중인 미루기 예약이 취소된다.
6. 퀵알람은 고른 분 뒤에 한 번 울리고 미션 없이 끌 수 있으며, 울린 뒤 목록에서 사라진다.
7. 한국어·영어 UI와 메모 재생, 기존 알람 데이터 보존, 장기간 앱 미실행·재부팅에 대한 동작을 확인한다.

### 11.10 상세 설계 결정 항목

- 시간대 이동 및 일광 절약 시간의 존재하지 않거나 중복되는 시각 처리 규칙.
- 미루기로 다시 울릴 시각이 같은 알람의 다음 정규 회차와 겹치거나 지나는 경우의 처리.
- 같은 시각에 여러 알람이 겹칠 때 실행 화면·미션·소리 처리 정책.
- 일회성 예약(미루기·퀵알람·예외 회차)의 OS 개수 한도와 동시에 둘 수 있는 퀵알람 수.
- 알람 삭제 시 연결된 날짜 예외와 미래 예약의 삭제 범위 및 확인 UI.
- 메모 길이·읽기 속도·음성 기본값, 플랫폼별 예약 가능 범위.

위 항목은 상세 설계에서 확정하며, 자동 처리 방식을 추정해 구현하지 않는다. 개발 진행 상태는 이 문서가 아니라 `CLAUDE.md`에서 관리한다.
